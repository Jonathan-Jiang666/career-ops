# Career Ops

Career Ops is an AI-assisted career operations agent designed to make the software engineering job search more structured, efficient, and repeatable.

## Purpose

This project reduces manual effort in the job search process so candidates can focus more on preparation, applications, and interviews instead of repeatedly searching, sorting, and tracking opportunities by hand.

## Key Features

- Job posting collection and processing
- Location and role relevance filtering
- Software engineering role matching
- Deduplication of previously tracked jobs
- Application status tracking
- Candidate-job fit evaluation
- Markdown/PDF report generation
- Repeatable career workflow automation

## Workflow Coverage

Career Ops helps automate key parts of a high-volume software engineering job search workflow:

- Collecting job postings
- Normalizing role data
- Filtering opportunities by location and relevance
- Deduplicating previously seen roles
- Ranking suitable positions
- Maintaining an application tracker with role status and history
